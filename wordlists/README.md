# Wordlists Directory

This directory contains wordlists used for various reconnaissance and scanning tasks.

## Included Wordlists

- `subdomains.txt` - Common subdomain names
- `parameters.txt` - Common parameter names
- `paths.txt` - Common paths and endpoints
- `secrets.txt` - Patterns for secret detection

## Usage

These wordlists are automatically used by the modular pipeline during:
- Subdomain enumeration
- Parameter discovery
- Content fuzzing
- Secret detection

## Adding Custom Wordlists

Add your custom wordlists to this directory and reference them in the configuration files.
